# שרת הבקנד של Gravity Maze 🚀

שרת אמיתי למשחק — הופך כל פעולה לרשת-מהירה:

| בלי שרת (textdb) | עם השרת |
|---|---|
| מתנות/עונשים מגיעים תוך ~10 שניות | מגיעים תוך **פחות משנייה** (דחיפת WebSocket ⚡) |
| באן נתפס בסבב הבא | בעיטה מיידית |
| שני אדמינים כותבים יחד → דריסה | כתיבות **אטומיות** — כלום לא הולך לאיבוד |
| הקליינט מכריע איזו שמירה חדשה | **השרת מכריע** — בטוח לכמה מכשירים |

## פריסה בחינם על Cloudflare (5 דקות, פעם אחת)

צריך רק חשבון Cloudflare חינמי (workers.dev). מתוך התיקייה `backend/`:

```bash
npm i -g wrangler      # 1) מתקינים את כלי הפריסה
wrangler login         # 2) נפתח דפדפן — מאשרים
wrangler deploy        # 3) מפרסמים
```

בסוף הפקודה השלישית מודפסת כתובת, למשל:

```
https://gravity-maze-backend.your-name.workers.dev
```

## חיבור המשחק (פעם אחת, מהאדמין)

1. נכנסים למשחק כאדמין → 👑 פאנל אדמין
2. מדביקים את הכתובת בשדה **"כתובת שרת בקנד"** ולוחצים **🔌 חבר**
3. זהו! המשחק:
   - בודק שהשרת אמיתי (ping)
   - **מייבא אוטומטית** את כל השחקנים הקיימים מהענן הישן
   - רושם את הכתובת בענן הישן — **כל השחקנים עוברים לשרת אוטומטית** בכניסה הבאה, בלי לעדכן אפליקציה

לניתוק: מרוקנים את השדה ולוחצים 🔌 חבר — כולם חוזרים ל-textdb.

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `worker.js` | השרת עצמו — Cloudflare Worker + Durable Object (אחסון קבוע + WebSocket) |
| `wrangler.toml` | הגדרות הפריסה |
| `dev-server.js` | אותו שרת בדיוק ל-Node — לבדיקות מקומיות או לאחסון עצמאי: `npm i ws && node dev-server.js 8787` |

## ה-API (למתעניינים)

| נתיב | מה עושה |
|---|---|
| `GET /api/ping` | זיהוי השרת + כמות שחקנים |
| `GET/POST /api/doc` | קריאה/כתיבה של כל המסמך (תאימות לאחור) |
| `POST /api/import` | ייבוא חד-פעמי מ-textdb (לא דורס קיימים) |
| `POST /api/register` | הרשמה אטומית (409 אם השם תפוס) |
| `POST /api/pw` | איפוס סיסמה |
| `POST /api/save` | שמירה — השרת מכריע מי מתקדם יותר |
| `POST /api/gift` | מתנה/עונש — מיזוג אטומי + דחיפה מיידית |
| `POST /api/claim` | משיכת דואר נכנס (אטומי) |
| `POST /api/ban` · `/api/summon` · `/api/live` · `/api/mm` | באנים, זימונים, נוכחות, שידוך תחרויות |
| `WS /ws?u=שם` | ערוץ דחיפה — השרת מודיע לשחקן ברגע שמחכה לו משהו |

השרת נשאר בחינם לגמרי בשימוש של המשחק (התוכנית החינמית של Cloudflare: 100,000 בקשות ביום).
