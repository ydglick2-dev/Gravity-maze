This project is not affiliated with, endorsed by, or connected to SYBO Games or Kiloo in any way. "Subway Surfers" is their trademark, and this is a personally-built tribute to the endless-runner genre they popularised — it is not the original game and does not contain any part of it.

There are no imported models, textures, sprites, fonts or sound files: the characters, trains, buildings, coins and every sound effect are generated procedurally in code at runtime. For personal, non-commercial use only.

What it is

A 3-lane endless runner rendered in real 3D: jump, roll, switch lanes, dodge trains, collect coins, and use power-ups — a coin magnet, a jetpack, super sneakers, a score multiplier and a hoverboard that absorbs one crash. There is a shop for characters, boards and upgrades, daily missions, a word challenge and a local high-score table.

The one deliberate deviation from the original design is the 🔓 UNLOCK ALL button in the top-right corner, which unlocks every character, board and upgrade and grants unlimited coins and keys.

Privacy

Progress is stored only in this browser, in localStorage. There is no account, no server, no analytics, no advertising and no network communication of any kind. Clearing site data erases everything.
