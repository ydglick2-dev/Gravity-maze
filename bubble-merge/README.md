# מיזוג בועות — אב-טיפוס

משחק ארקייד בסגנון "סוויקה": מפילים בועות לתוך מיכל, שתי בועות מאותה דרגה שנוגעות מתמזגות
לבועה גדולה יותר. אם הערימה חוצה את הקו האדום למשך כשתי שניות — המשחק נגמר.

## הפעלה

קובץ `index.html` יחיד, ללא תלויות וללא שרת. אפשר לפתוח אותו ישירות בדפדפן,
או להגיש את התיקייה (`npx http-server bubble-merge`) ולפתוח בטלפון.

## שליטה

- **מגע/עכבר** — גרירה כדי לכוון, שחרור כדי להפיל
- **מקלדת** — חצים כדי לכוון, רווח כדי להפיל

## מה יש בפנים

- מנוע פיזיקה של עיגולים: אימפולסים עם חיכוך משיקי ותיקון חדירה איטרטיבי,
  3 תת-צעדים ו-5 איטרציות לפריים. רחב-פאזה של sweep-and-prune לפי ציר X.
- 11 דרגות בועות. מיזוג שתי בועות בדרגה העליונה מפוצץ את שתיהן ומזכה ב-200 נקודות.
- קומבו פר-הפלה: שרשרת מיזוגים מאותה בועה מכפילה את הניקוד עד ×3.
- שיא נשמר ב-`localStorage`, אודיו פרוצדורלי ב-Web Audio, רטט, וחלקיקים.
- מותאם לנייד: יחס לוח שמתאים את עצמו למסך, שוליים בטוחים, ושמירה על מצב המשחק
  בעת סיבוב המכשיר.

## פרמטרים לכיול

כל קבועי התחושה מרוכזים בראש הסקריפט תחת `פיזיקה`:
`GRAV` (כבידה), `REST` (אלסטיות), `FRIC` (חיכוך), `DROP_CD` (קצב הפלה),
`DANGER_T` (כמה זמן מעל הקו עד הפסד). גדלי הבועות נגזרים מ-`R0` ו-`RK`.

## מה חסר לפני שחרור

- חיבור ללוח המובילים, למטבעות ולתיבות של המשחק הראשי
- סקינים לבועות
- מצב "אתגר יומי" עם רצף בועות זהה לכל השחקנים
