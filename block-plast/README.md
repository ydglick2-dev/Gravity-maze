# Block Plast

משחק פאזל בלוקים 8×8 כ-PWA. **בלי פרסומות, בלי מעקב, בלי בקשות רשת חיצוניות** — הכול רץ בדפדפן.

## איך משחקים

גוררים חלקים מהמגש אל הלוח. שורה או עמודה שמתמלאת מתנקה. אין סיבוב לחלקים.
המשחק נגמר כשאף חלק מהשלושה שבמגש לא נכנס יותר לשום מקום.

**ניקוד:** תא שהונח = 1 נקודה. ניקוי קווים = `10 × מספר_הקווים²`, ובונוס קומבו
של 50% נוסף לכל שלב קומבו מעבר לראשון. הקומבו עולה בכל מהלך שמנקה ומתאפס במהלך שלא.

**פיצ'רים:** ביטול מהלך, המשך חינם אחרי סוף משחק (פעם אחת למשחק), סטטיסטיקות,
4 ערכות צבע, צלילים (WebAudio, בלי קבצי שמע), רטט, חלקיקים ורעידת מסך.
הכול נשמר ב-`localStorage` על המכשיר בלבד.

## איך זה מצויר

כל המשחק מצויר על **קנבס אחד** בלולאת `requestAnimationFrame`; רק ה-HUD, השכבות
והטוסטים הם DOM. הגרירה לא נוגעת ב-DOM בכלל: המיקום מתעדכן מ-`getCoalescedEvents`
כדי לא לאבד דגימות מגע בין פריימים, ותא היעד מחושב מחדש רק כשהוא באמת משתנה.
הלולאה נעצרת כשאין אנימציה פעילה ומתעוררת מחדש בעת הצורך, כדי לא לשרוף סוללה.

החלק הנגרר מרחף מעל האצבע (1.45 תאים) ונע ברציפות — לא נצמד לרשת — ומתחתיו מסומן
מקום הנחיתה בריבועים בהירים מנופחים, כך שנשארת מסגרת גלויה סביב החלק.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל המשחק — HTML, CSS, קנבס ו-JS בקובץ אחד, ללא תלויות |
| `sw.js` | Service Worker — מטמון `blockplast-v2`, מאפשר משחק אופליין |
| `manifest.webmanifest` | הגדרות ההתקנה כאפליקציה |
| `_headers` | `no-cache` ל-`index.html`/`sw.js` כדי שעדכונים יגיעו |
| `privacy.html` | הצהרת פרטיות |
| `tools/` | סקריפטים לפיתוח בלבד — לא נכנסים ל-ZIP שנפרס |

## פיתוח

```bash
# יצירת האייקונים מחדש
node block-plast/tools/make-icons.mjs

# בדיקת עשן מקומית (מרימה שרת בעצמה)
node block-plast/tools/smoke-test.mjs

# בדיקת עשן על הגרסה החיה
node block-plast/tools/smoke-test.mjs https://nova-deploy-hub.dtubugk.chatgpt.site/s/block-plast

# אריזה, העלאה ל-NOVA ואימות
node block-plast/tools/deploy.mjs
```

בדיקת העשן מריצה 53 בדיקות: טעינת משאבים, רישום ה-Service Worker, גרירה אמיתית
עם עכבר (כולל מדידת קצב הפריימים בזמן גרירה), ניקוי שורות, קומבו, ביטול מהלך,
שמירת שיא, ערכות צבע, פינוי מקום ל-UI של המארח, ו-5 משחקים מלאים אוטומטיים.
מכיוון שהלוח מצויר על קנבס, הבדיקות קוראות את מצב המשחק דרך `window.__bp`
ודוגמות פיקסלים מהקנבס במקום לחפש אלמנטים ב-DOM.
צילומי מסך נשמרים ב-`block-plast/.smoke-shots/`.

כשמעבירים כתובת, הבדיקה מורידה את הקבצים שהשרת באמת מגיש — כולל כל מה שהמארח
הזריק לתוכם — ומריצה עליהם את אותן בדיקות מול שרת מקומי.

## הרצה תחת מארח

NOVA מגישה את תוכן ה-ZIP תחת `<אתר>/game/`, מפנה את שורש האתר לשם, ומזריקה לדף
שכבת תאימות: היא מסתירה את `navigator.serviceWorker` (ורושמת Service Worker משלה
ברמת האתר), עוטפת את `localStorage`, ומוסיפה כפתור «התקן אפליקציה» צף בתחתית המסך.
המשחק מזהה כל אלמנט צף בתחתית שאינו שלו ומפנה לו מקום, כדי שהמגש לא יוסתר.
כשמארחים את הקבצים ישירות, ה-Service Worker וה-manifest שכאן משמשים כרגיל.

## מקוריות

מכניקת הז'אנר (רשת, חלקים, ניקוי שורות) מומשה כאן מאפס. כל הקוד, העיצוב,
הצלילים והאייקונים מקוריים — לא הועתקו נכסים, קוד או מיתוג משום משחק אחר.
