# Gravity Maze 🎱

משחק מבוך-הטיה (PWA) בקובץ HTML אחד: 1,000 שלבים, 100 עולמות, בוסים, ראנר אינסופי, תחרות חיה (PeerJS), אתגר יומי, קווסטים, תיבות, סקינים ולובי תלת-ממד (Three.js).

## הפעלה

המשחק סטטי לחלוטין — כל שרת קבצים יעבוד:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

לפריסה: Cloudflare Pages / Netlify / GitHub Pages (קובץ `_headers` כלול). חיישן ההטיה דורש HTTPS; במחשב אפשר לשחק עם חצים / WASD, ו-Escape משהה.

## שינויים קודמים (v51) — תיקון שחקני אייפון 🍏

- **שמות עם תווים בלתי-נראים תוקנו:** המקלדת של אייפון מוסיפה לפעמים סימן כיווניות סמוי (U+200F) לשם המשתמש — השחקן נרשם, אבל חיפוש/מתנה/חברות בשם ה"רגיל" לא מצאו אותו. עכשיו כל שם מנוקה מתווים סמויים בכל נקודת כניסה (הרשמה, יעד אדמין, חברים, מרוצים) — גם בקליינט וגם בשרת. נתונים קיימים תוקנו בשרת החי.
- **כתובת השרת צרובה בקוד:** המשחק מתחבר לשרת הרשמי מיד, כבר בטעינה הראשונה — בלי תלות בגילוי דרך textdb (שנשאר כגיבוי, ואפשר להתנתק דרך פאנל האדמין).
- **גשר לגרסאות ישנות:** השרת מסנכרן מ-textdb כל ~2 דקות שחקנים חדשים ושמירות מתקדמות — מי שנרשם ממכשיר עם גרסה ישנה של המשחק עדיין נקלט אצל האדמין.

## שינויים קודמים (v50) — שרת בקנד אמיתי 🚀

- **נוסף שרת בקנד מלא** (`backend/` — Cloudflare Worker חינמי, או Node): דחיפת WebSocket מיידית, כתיבות אטומיות והכרעת שמירות בצד השרת. פריסה בשלוש פקודות — ראו `backend/README-he.md`.
- **כשהשרת מחובר:** מתנות/עונשים/באנים/זימונים מגיעים לשחקן תוך **פחות משנייה** (נמדד: ~0.4 שניות, לעומת ~10 שניות ב-textdb). הרשמות אטומיות (אין שני שחקנים עם אותו שם), מתנות לא הולכות לאיבוד, ושמירה בין מכשירים מוכרעת בשרת.
- **חיבור בלחיצה אחת:** האדמין מדביק את כתובת השרת בפאנל (🔌 חבר). המשחק מייבא את כל השחקנים מהענן הישן, וכל השחקנים עוברים לשרת **אוטומטית** בכניסה הבאה — בלי לעדכן אפליקציה.
- בלי שרת הכול ממשיך לעבוד כרגיל דרך textdb — השרת הוא שדרוג, לא דרישה.

## שינויים קודמים (v30) — תיקון התחברות ומסך אבחון 🔑

- **סנכרון התקדמות בענן למשתמשים מחוברים:** עד עכשיו הענן שמר רק שם+סיסמה — ההתקדמות הייתה תקועה במכשיר. עכשיו השמירה המלאה (שלבים, כוכבים, מטבעות, תיבות, סקינים, הישגים) נדחפת לענן ברקע (כל 15 שניות כשיש שינוי, וגם ביציאה מהעמוד) ונמשכת אוטומטית בכל התחברות — מכל מכשיר ומכל דפדפן.
- **פתרון קונפליקטים חכם:** ההשוואה נעשית לפי כמות התקדמות (מדדים שרק עולים), כך ששמירה ריקה/ישנה לעולם לא דורסת התקדמות אמיתית — גם אם השעון במכשיר לא מדויק.
- **עמידות לחסימת אחסון:** אם הדפדפן חוסם localStorage (למשל כשהמשחק רץ בתוך iframe של אתר פרסום, או במצב פרטי) — המשחק לא נשבר: יש אחסון זמני לסשן, אזהרה ברורה למשתמש, ולמחוברים הכול ממשיך להישמר בענן.
- הודעה במסך הכניסה שמסבירה שהתחברות = שמירה בענן.

## שינויים קודמים (v28)

- **תיקון קריטי:** `emit()`/`emitIn()` הפנו למשתנה `parts` שלא קיים — כל אפקטי החלקיקים (כוכבים, באמפרים, פורטלים, מפתחות, אפקטי מוות וניצחון) זרקו שגיאה. תוקן ל-`particles`.
- **תיקון UI:** הוסרה שורת כפתורים כפולה ("תפריט"/"לובי" הופיעו פעמיים) במסך סיום שלב.
- **תיקון גיימפליי:** עם סקין-הכוח "האטה", הספינר המצויר לא תאם את מיקום ההתנגשות בפועל — עכשיו הציור והפיזיקה מסונכרנים.
- מקש **Escape** משהה/ממשיך את המשחק במחשב.
- טוסט "🔥 קומבו" מהכוכב השלישי ברצף, והצגת המטבעות שהרווחתם במסך סיום השלב.
- רשת בחירת השלבים (1,000 כפתורים) נבנית ב-DocumentFragment — פתיחה מהירה יותר.
- ניקוי כפילויות קוד ב-`resize()` והעלאת גרסת המטמון של ה-Service Worker ל-v28.
