# נובה 9 — NOVA-9

חמישה משחקים בכיס אחד. אפליקציית PWA שמותקנת ישירות מהדפדפן, וגם APK לאנדרואיד.
עברית מלאה, RTL, ומותאם לנייד: מסך מגע, רטט, סאונד — הכול נוצר בקוד, בלי קבצי מדיה.

> הריפו מכיל גם את המשחק הקודם, `maze-v27-audiofix.zip` (Gravity Maze), שנשאר כמו שהוא.

## המצבים

| מצב | מה זה | איך משחקים |
|---|---|---|
| **קפיצת כבידה** | ארקייד לחיצה אחת, עלייה אינסופית | הקשה הופכת את כיוון הכבידה. חלוף קרוב ליד מכשול = מכפיל בונוס |
| **מעגלי אור** | 40 שלבי פאזל לייזר | סובב מראות עד שכל הגבישים מוארים. פתרון ביעד המהלכים = 3 כוכבים |
| **ריצת נובה** | רוגלייק הישרדות | זז עם הג׳ויסטיק, הנשק יורה לבד. כל עלייה ברמה = בחירת שדרוג מתוך שלושה. בוס בכל גל חמישי |
| **בוגד בתחנה** | דדוקציה חברתית מול בוטים | 7 בתחנה, אחד בוגד (לפעמים אתה). משימות, גופות, אספות והצבעה |
| **זירת כוכבים** | קרב 3 נגד 3 מול בוטים | חצי מסך שמאל = תנועה, ימין = כיוון וירי. 10 גבישים והחזקה של 15 שניות = ניצחון |

מטבעות מכל המצבים נאספים לארנק אחד וקונים עיצובים בחנות; ההתקדמות נשמרת במכשיר.

## הפעלה

```bash
cd web && python3 -m http.server 8000
# ואז http://localhost:8000
```

חייב לרוץ דרך שרת (ולא `file://`) — המשחק בנוי ממודולי ES.
בפריסה לאתר (GitHub Pages / Netlify וכו׳) מגישים את תיקיית `web/`, והמשחק מוצע להתקנה כאפליקציה.

## בניית ה-APK

הקובץ המוכן נמצא ב־[`dist/nova9.apk`](dist/nova9.apk) — חתום בחתימת debug, ולכן בהתקנה
צריך לאשר "התקנה ממקור לא ידוע". לבנייה מחדש:

```bash
./build-apk.sh
```

צריך JDK 17+, Gradle 8.x ו-Android SDK (דרך `ANDROID_HOME` או `android/local.properties`).
הסקריפט מעתיק את `web/` לתוך נכסי האפליקציה ומריץ `gradle assembleDebug`.
יש גם workflow ב-GitHub Actions שבונה APK בכל דחיפה ומעלה אותו כ-artifact.

## מבנה

```
web/                     המשחק (PWA)
  index.html             מעטפת ומסכי UI
  css/style.css
  js/core.js             מנוע: לולאה, קלט, אודיו, חלקיקים, שמירה
  js/ui.js               מסכים, חנות, הגדרות
  js/main.js             ניתוב בין המצבים
  js/modes/*.js          חמשת המשחקים
  sw.js                  service worker (עבודה במצב אופליין)
android/                 מעטפת WebView לאנדרואיד
dist/nova9.apk           ה-APK הבנוי
```

## הערות טכניות

- **אודיו**: כל הצלילים והמוזיקה נוצרים ב-WebAudio בזמן אמת — לכל מצב יש קצב, סולם וגוון משלו.
- **פאזלים**: 40 השלבים נוצרים מ-seed קבוע, כך ששלב 12 הוא תמיד אותו שלב. הבנייה מבטיחה שקיים פתרון,
  ונבדק אוטומטית שאף שלב לא מתחיל פתור ושכל 40 פתירים.
- **ניווט בוטים**: בתחנה יש גרף מעברים בין החדרים (BFS דרך פתחי הדלתות), כדי שהבוטים לא ייתקעו בפינות.
- **APK**: המשחק מוגש דרך `WebViewAssetLoader` ולא `file://`, כי מודולי ES ו-localStorage דורשים origin אמיתי.
