# מצא טלפון — Find My Phone

אפליקציית אנדרואיד שרצה ברקע, מאזינה כשהמסך כבוי, וכשאומרים **"מצא טלפון"** מפעילה
צפירה חזקה כדי לאתר את המכשיר. אפשר להפעיל את הצפירה גם על ידי שליחת הודעה בצ'אט
(WhatsApp / Telegram / SMS) שכתוב בה "מצא טלפון".

**הקובץ להתקנה:** [`find-my-phone.apk`](find-my-phone.apk)

> בריפו נשאר גם `maze-v27-audiofix.zip` — משחק ווב ישן שאינו קשור לאפליקציה הזו.

---

## מה האפליקציה עושה

| טריגר | מה קורה |
|---|---|
| אומרים "מצא טלפון" (מסך כבוי) | צפירה |
| מגיעה הודעת צ'אט/SMS עם "מצא טלפון" | צפירה |
| כפתור "בדוק צפירה" באפליקציה | צפירה |

**הצפירה** = צליל אזעקה בעוצמה מקסימלית (עוקף מצב שקט), רטט חזק, הבהוב הפנס האחורי,
והדלקת המסך עם כפתור עצירה ענק מעל מסך הנעילה. היא נעצרת בכפתור, מהתראה, באמירת
"עצור"/"מצאתי", או לבד אחרי שתי דקות.

## התקנה

1. העתק את `find-my-phone.apk` לטלפון (כבל / Drive / WhatsApp לעצמך).
2. פתח את הקובץ. אנדרואיד יבקש לאשר **"התקנת אפליקציות לא מוכרות"** — אשר.
3. פתח את האפליקציה **מצא טלפון**.
4. עבור על הצ'קליסט במסך הראשי ולחץ "תקן" בכל שורה אדומה:

| מה | למה זה נחוץ |
|---|---|
| הרשאת מיקרופון | בלעדיה אין זיהוי קולי |
| הצגת התראות | נדרשת כדי לרוץ ברקע ולהציג את מסך העצירה |
| גישה להתראות צ'אט | הטריגר מהודעות; זה גם מה שעובד מיד אחרי אתחול |
| ללא הגבלת סוללה | בלעדיה אנדרואיד יסגור את ההאזנה אחרי כמה דקות |
| התראה במסך מלא | מדליקה את המסך מעל מסך הנעילה |

5. לחץ **"הפעל האזנה"**, ואז **"בדוק צפירה"** כדי לוודא שהכול עובד.

### במכשירי Xiaomi / Samsung / Huawei / OnePlus

ליצרנים האלה יש מנגנון סגירה אגרסיבי משלהם, בנוסף לאנדרואיד. בלי זה ההאזנה תיסגר
אחרי כמה שעות:

- **הפעלה אוטומטית / Autostart** — הפעל עבור האפליקציה.
- **חיסכון בסוללה לאפליקציה** — קבע "ללא הגבלה" / "Unrestricted".
- **נעילת האפליקציה במסך האחרונות** (Recents) — נעל, כדי שניקוי אפליקציות לא יסגור אותה.

### זיהוי דיבור ללא אינטרנט

ברירת המחדל היא לבקש זיהוי מקומי, עם נפילה חזרה לזיהוי דרך הרשת. כדי שיעבוד גם בלי
אינטרנט התקן את חבילת העברית:
**הגדרות ← Google ← הגדרות לאפליקציות של Google ← חיפוש, מדריך דיגיטלי וקלט קולי ←
קלט קולי ← זיהוי דיבור לא מקוון ← עברית**.

## מגבלות שכדאי להכיר

- **אחרי הפעלה מחדש של הטלפון** אנדרואיד 14 ומעלה אוסר על אפליקציה לפתוח שירות
  מיקרופון מהרקע. תופיע התראה "ההאזנה מושהית" — הקשה אחת עליה מחזירה את ההאזנה.
  **טריגר הצ'אט ממשיך לעבוד אוטומטית גם בלי ההקשה הזו.**
- **האזנה רק כשהמסך כבוי** — זו הבחירה שנקבעה כדי לחסוך בסוללה. כשהמסך דלוק הטלפון
  ממילא בידיים, והטריגר מהצ'אט עדיין פעיל.
- **זיהוי קולי אינו מושלם** — מרחק גדול, רעש רקע או טלפון מתחת לכרית יפגעו בו. לכן
  טריגר הצ'אט הוא הגיבוי המומלץ כשהטלפון באמת אבד.
- ה-APK חתום בחתימת פיתוח (debug). זה מספיק להתקנה ידנית; זה לא מתאים להעלאה לחנות.

## פרטיות

מה שנשמע במיקרופון וטקסט ההתראות מושווים למשפט הטריגר **בזיכרון בלבד**. שום הקלטה,
תמלול או תוכן הודעה לא נשמרים במכשיר ולא נשלחים לשום מקום. האפליקציה אינה מבקשת
הרשאת אינטרנט; זיהוי הדיבור עצמו מתבצע על ידי מנוע Google שכבר מותקן במכשיר.

## פיתוח

```bash
export ANDROID_HOME=/path/to/android-sdk     # דורש platforms;android-35 ו-build-tools;35.0.0
./gradlew :app:assembleDebug                 # -> app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest             # בדיקות התאמת הביטוי
./gradlew :app:lintDebug
```

Kotlin · minSdk 26 (אנדרואיד 8) · targetSdk 34 · תלות יחידה: `androidx.core-ktx`.

| קובץ | תפקיד |
|---|---|
| `FinderService.kt` | שירות קדמי מסוג microphone; מפעיל האזנה לפי מצב המסך |
| `VoiceListener.kt` | לולאת `SpeechRecognizer` עם הפעלה מחדש ו-backoff |
| `TriggerMatcher.kt` | נרמול עברית והתאמת ביטויי הפעלה/עצירה (מכוסה בטסטים) |
| `AlarmService.kt` | שירות קדמי מסוג mediaPlayback; מריץ את הצפירה |
| `Alarm.kt` | צליל, רטט ופנס |
| `AlarmActivity.kt` | מסך העצירה מעל מסך הנעילה |
| `ChatNotificationListener.kt` | טריגר מהודעות צ'אט |
| `BootReceiver.kt` | שחזור אחרי אתחול |
