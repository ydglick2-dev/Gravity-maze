# כרטיסיות — מימוש ייחוס

**זה לא הקוד של המפגש.** זה המימוש שאתה מחזיק כדי לדעת מראש איפה הוא ייתקע, ומה להדביק אם השעון נגמר. הוא כותב את שלו מאפס לפי `SESSION-1.md`.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה כולה — HTML, CSS ו-JS בקובץ אחד. עובד גם בפתיחה ישירה מהדיסק |
| `manifest.json` | הופך אותה ל-PWA: אייקון על מסך הבית, פתיחה במסך מלא |
| `icon-192/512/512-maskable.png` | אייקוני ה-manifest |
| `icon-180.png` | `apple-touch-icon` לאייפון |
| `IDEAS.md` | מה שנדחה למפגשים הבאים |

## פרסה

העתק את **תוכן התיקייה הזאת** לשורש ה-repo החדש (לא את התיקייה עצמה — `index.html` חייב לשבת בשורש), ואז Settings → Pages → main → Save.

`start_url` ו-`scope` ב-manifest הם `./`, כך שזה עובד גם תחת נתיב משנה של Pages כמו `user.github.io/flashcards/`.

## החלטות שכדאי להכיר לפני שהוא שואל

**אין קריאת API.** מפתח בצד לקוח על אחסון ציבורי נסרק תוך ימים. במקומו: כפתור "העתק פרומפט" → הוא מדביק בצ'אט → מעתיק את ה-JSON חזרה. הפרומפט נשאר גלוי ועריך במקום מוחבא מאחורי `fetch`.

**אין service worker,** למרות שזה PWA. SW עם קאש הוא באג שקט למתחיל — אתה מעלה גרסה חדשה והטלפון ממשיך להציג את הישנה. בלעדיו "הוסף למסך הבית" עדיין עובד, האפליקציה עדיין נפתחת במסך מלא, וכל העלאה נראית מיד. המחיר היחיד הוא שאין עבודה אופליין.

**אין localStorage.** מפגש 2.

**`parseCards()` מקבל יותר ממה שהפרומפט מבטיח** — גם מערך חשוף בלי `cards`, גם טקסט לפני ואחרי, גם גדרות ```` ``` ````. זה לא סתירה לפרומפט; זה הכרה בכך שמודלים סוטים, ושהמשתמש לא אמור לשלם על זה.

**אין ניסיון חוזר אוטומטי ואין מתקן JSON.** הודעת השגיאה מכילה את התיקון עצמו ("החזר שוב, רק JSON") כדי שחבר שנתקע בשבע בערב יפתור את זה לבד. הבן אדם הוא מנגנון הניסיון החוזר.

**הכפתורים "ידעתי / לא ידעתי" מופיעים רק אחרי היפוך.** אחרת אפשר לענות בלי להיזכר, וזו כל הפואנטה של כרטיסייה.

**הסט הקודם שורד שגיאה.** `btnLoad` נכשל → מציג הודעה ויוצא, בלי לגעת ב-`all`/`queue`. אף פעם לא מוחקים משהו שעבד.

## איפה הוא ייתקע — לפי סדר הסתברות

1. **`i++` לפני או אחרי הבדיקה.** קלאסי. אם הוא בודק `i >= queue.length` לפני הקידום הוא יפספס את הכרטיסייה האחרונה.
2. **`queue = failed` בלי `failed = []`.** אז הסבב השני דוחף לתוך המערך שהוא בעצמו קורא, והלולאה לא נגמרת לעולם. זה הבאג הכי מלמד במפגש — תן לו להיתקל בו.
3. **`textContent` מול `innerHTML`.** אם הוא ילך ל-`innerHTML`, שאלה עם `<` תשבור את העמוד.
4. **`onclick` שנרשם לפני שהאלמנט קיים.** ה-`<script>` כאן בסוף ה-`<body>` בכוונה.
5. **גופן מתחת ל-16px ב-`textarea`** — ספארי מזמזם זום בכל פוקוס וזה נראה שבור בנייד.

## בדיקה מקומית

```
npx http-server -p 8099 .
```

ואז `http://127.0.0.1:8099/`. פתיחה ישירה של הקובץ מהדיסק עובדת גם, אבל ה-manifest לא ייטען ב-`file://`.
